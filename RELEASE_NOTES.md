# Student Schedule Finder 1.3.0 — release candidate

Free WordPress student schedule lookup with:

- Individual student management and exact full-name search.
- CSV and native Excel .xlsx import with preview.
- Bulk editing of shared fields and confirmed bulk deletion.
- Responsive student result cards.
- WordPress-native permissions, validation and database APIs.

**Installation:** Download `student-schedule-finder.zip` below and upload it through WordPress Plugins > Add New > Upload Plugin. Use `[student_lookup]` to display the form.

**Verification:** PHP syntax and standalone import/bulk-input regressions passed on PHP 7.0 and PHP 8.3. Full WordPress database/permission/theme integration and Plugin Check remain pending. Test on staging first.

**Access:** Name-only lookup is public and does not verify parent identity. Distributed samples and fixtures are fictional.

**Migration:** Deactivate Student Schedule Lookup before activating this plugin. The existing table and shortcode are retained.

This prerelease is not a WordPress.org-approved version.
